# Folder: scripts

> Trigger: When this folder's structure/responsibilities/file list changes, update this document.
> 触发条件:当本文件夹的结构/职责/文件列表变化时，更新此文档。

Scripts automate repeatable local or production maintenance tasks. / 脚本自动化可重复的本地或生产维护任务。
They may orchestrate builds and deployment tools but must not contain secrets. / 它们可以编排构建与部署工具，但不得包含密钥。
All production credentials must come from environment variables or host-local config. / 所有生产凭据必须来自环境变量或宿主机本地配置。

## Files
- `deploy-member-assets-to-oss.sh`: scripts - lockfile-syncs member H5 dependencies, builds it, and syncs `dist/assets` to Alibaba Cloud OSS / 按锁文件同步会员端依赖、构建并同步 `dist/assets` 到阿里云 OSS
- `member-load-test.mjs`: scripts - runs the controlled synthetic member read flow and concurrent registration submission test / 执行受控合成会员访问流程与并发报名提交测试
- `production-update.sh`: scripts - orchestrates one-command production updates for frontend, backend, or both; frontend assets auto-fall back to a local build when OSS credentials are absent / 编排前端、后端或完整生产更新的一键流程；缺少 OSS 凭据时前端资源自动回退为本地构建
- `verify-member-cdn.sh`: scripts - checks origin HTML asset references and read-only CDN edge responses / 检查源站 HTML 资源引用与只读 CDN 边缘响应
